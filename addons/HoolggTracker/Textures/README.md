# HoolggTracker Textures

Place the following files here:
- `HoolggTracker_Icon.tga` — 64x64 addon icon (shown in addon list)
- `HoolggTracker_Minimap.tga` — 32x32 minimap button icon (circular mask applied by LibDBIcon)

Both should be TGA format (uncompressed, no alpha for minimap icon).
The minimap icon should be a circular design on a black/transparent background.
