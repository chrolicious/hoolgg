# HoolggTracker Libraries

This addon requires the following libraries. Copy each library's `.lua` file into the appropriate subdirectory.

## Required Libraries

### LibStub
- Source: https://repos.wowace.com/wow/libstub/trunk/LibStub.lua
- Place at: `libs/LibStub/LibStub.lua`

### CallbackHandler-1.0 (required by AceDB)
- Source: https://www.wowace.com/projects/callbackhandler
- Place at: `libs/CallbackHandler-1.0/CallbackHandler-1.0.lua`

### AceDB-3.0
- Source: https://www.wowace.com/projects/ace3 (AceDB module)
- Place at: `libs/AceDB-3.0/AceDB-3.0.lua`

### LibDataBroker-1.1 (required by LibDBIcon)
- Source: https://www.wowace.com/projects/libdatabroker-1-1
- Place at: `libs/LibDataBroker-1.1/LibDataBroker-1.1.lua`

### LibDBIcon-1.0
- Source: https://www.wowace.com/projects/libdbicon-1-0
- Place at: `libs/LibDBIcon-1.0/LibDBIcon-1.0.lua`

## Quick Install (CurseForge Packager)

All libraries are MIT licensed. The easiest way to get them is to:
1. Download the latest release of any AceDB-using addon
2. Extract the `libs/` folder
3. Keep only the libraries listed above

Or use the WoW Ace packager with a `.pkgmeta` file (see https://wowace.com/packager).
